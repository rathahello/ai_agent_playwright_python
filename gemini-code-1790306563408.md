# SauceDemo Test Specification for Playwright (Python)

Target URL: `https://www.saucedemo.com/`
Framework: `pytest-playwright`
Design Pattern: Page Object Model (POM)
Target Directory Structure:
- `pages/` (Page classes)
- `tests/` (Test cases)
- `conftest.py` (Fixtures and browser setup)

---

## 1. Authentication (`tests/test_auth.py`)

### TC-AUTH-001: Successful Login with Standard User
- **Preconditions**: User is on login page.
- **Steps**:
  1. Fill `#user-name` with `standard_user`.
  2. Fill `#password` with `secret_sauce`.
  3. Click `#login-button`.
- **Expected Results**:
  - URL equals `https://www.saucedemo.com/inventory.html`.
  - Header text `.app_logo` is "Swag Labs".
  - Inventory container `.inventory_list` is visible.

### TC-AUTH-002: Login Attempt with Locked-Out User
- **Preconditions**: User is on login page.
- **Steps**:
  1. Fill `#user-name` with `locked_out_user`.
  2. Fill `#password` with `secret_sauce`.
  3. Click `#login-button`.
- **Expected Results**:
  - Error container `[data-test="error"]` is visible.
  - Error text contains "Epic sadface: Sorry, this user has been locked out.".

### TC-AUTH-003: Login Attempt with Empty Username
- **Preconditions**: User is on login page.
- **Steps**:
  1. Leave `#user-name` empty.
  2. Fill `#password` with `secret_sauce`.
  3. Click `#login-button`.
- **Expected Results**:
  - Error text contains "Epic sadface: Username is required".

### TC-AUTH-004: Login Attempt with Empty Password
- **Preconditions**: User is on login page.
- **Steps**:
  1. Fill `#user-name` with `standard_user`.
  2. Leave `#password` empty.
  3. Click `#login-button`.
- **Expected Results**:
  - Error text contains "Epic sadface: Password is required".

### TC-AUTH-005: Login Attempt with Invalid Credentials
- **Preconditions**: User is on login page.
- **Steps**:
  1. Fill `#user-name` with `invalid_user`.
  2. Fill `#password` with `wrong_password`.
  3. Click `#login-button`.
- **Expected Results**:
  - Error text contains "Epic sadface: Username and password do not match any user in this service".

## 2. Inventory & Product Browsing (`tests/test_inventory.py`)

### TC-INV-001: Verify Inventory Items Display
- **Preconditions**: Logged in as `standard_user`.
- **Steps**:
  1. Inspect `.inventory_item` collection.
- **Expected Results**:
  - Count of items equals 6.
  - Every item contains a non-empty name, description, price, and image.

### TC-INV-002: Product Sorting - Name (A to Z) & (Z to A)
- **Preconditions**: Logged in as `standard_user`.
- **Steps**:
  1. Select sorting dropdown `[data-test="product-sort-container"]` option `az`.
  2. Extract all `.inventory_item_name` text and verify ascending alphabetical order.
  3. Select sorting dropdown option `za`.
  4. Extract all `.inventory_item_name` text and verify descending alphabetical order.
- **Expected Results**:
  - Product names match sorted lists strictly.

### TC-INV-003: Product Sorting - Price (Low to High) & (High to Low)
- **Preconditions**: Logged in as `standard_user`.
- **Steps**:
  1. Select sorting option `lohi`.
  2. Parse `.inventory_item_price` numbers and verify ascending numeric order.
  3. Select sorting option `hilo`.
  4. Parse `.inventory_item_price` numbers and verify descending numeric order.
- **Expected Results**:
  - Prices sort accurately according to numerical values.

### TC-INV-004: View Product Details
- **Preconditions**: Logged in as `standard_user`.
- **Steps**:
  1. Click first `.inventory_item_name`.
- **Expected Results**:
  - Navigates to `inventory-item.html?id=<id>`.
  - Item details page displays item name, description, price, and "Back to products" button.

## 3. Shopping Cart (`tests/test_cart.py`)

### TC-CART-001: Add Item to Cart from Inventory
- **Preconditions**: Logged in as `standard_user`.
- **Steps**:
  1. Click "Add to cart" on `Sauce Labs Backpack`.
- **Expected Results**:
  - Button text changes to "Remove".
  - Shopping cart badge `.shopping_cart_badge` displays `1`.

### TC-CART-002: Remove Item from Cart on Inventory Page
- **Preconditions**: Item added to cart.
- **Steps**:
  1. Click "Remove" button on the item.
- **Expected Results**:
  - Button toggles back to "Add to cart".
  - Shopping cart badge `.shopping_cart_badge` disappears or is detached.

### TC-CART-003: Cart Persistence Across Pages
- **Preconditions**: Add 2 items to cart from inventory.
- **Steps**:
  1. Click `.shopping_cart_link`.
- **Expected Results**:
  - Navigates to `cart.html`.
  - Displays exactly 2 `.cart_item` elements matching added items.

### TC-CART-004: Remove Item from Cart Page
- **Preconditions**: 2 items present in `cart.html`.
- **Steps**:
  1. Click "Remove" button on one item.
- **Expected Results**:
  - Item count drops to 1.
  - Cart badge updates to `1`.

## 4. Checkout Flow (`tests/test_checkout.py`)

### TC-CHK-001: End-to-End Successful Checkout
- **Preconditions**: Logged in, cart has at least 1 item, user on `cart.html`.
- **Steps**:
  1. Click `#checkout`.
  2. Fill `[data-test="firstName"]` with `John`.
  3. Fill `[data-test="lastName"]` with `Doe`.
  4. Fill `[data-test="postalCode"]` with `12345`.
  5. Click `#continue`.
  6. Verify item total + tax matches total amount on step two.
  7. Click `#finish`.
- **Expected Results**:
  - URL is `https://www.saucedemo.com/checkout-complete.html`.
  - Header `.complete-header` contains "Thank you for your order!".
  - Cart badge is cleared.

### TC-CHK-002: Checkout Validation - Missing Required Fields
- **Preconditions**: User on `checkout-step-one.html`.
- **Steps**:
  1. Leave all input fields blank.
  2. Click `#continue`.
- **Expected Results**:
  - Error message displayed: `Error: First Name is required`.
  3. Fill first name, leave last name blank, click `#continue`.
- **Expected Results**:
  - Error message displayed: `Error: Last Name is required`.
  4. Fill last name, leave postal code blank, click `#continue`.
- **Expected Results**:
  - Error message displayed: `Error: Postal Code is required`.

### TC-CHK-003: Cancel Checkout Flow
- **Preconditions**: User on `checkout-step-one.html`.
- **Steps**:
  1. Click `#cancel`.
- **Expected Results**:
  - User is returned to `cart.html` with cart items intact.
